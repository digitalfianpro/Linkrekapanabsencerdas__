Instalasi Bot — Sekali Saja

Setelah deployment pertama, perubahan data kelas/template cukup disinkron dari aplikasi. Tidak perlu mengganti kode Apps Script lagi.

1. Salin kode installer
2. Tempel ke Code.gs
3. Deploy sebagai Web App
4. Tempel URL /exec & Sinkronkan
Penting: gunakan Deploy → New deployment → Web app, jalankan sebagai akun Anda, dan izinkan akses yang diperlukan agar Fonnte dapat memanggil URL tersebut. Jangan memasukkan token Fonnte ke kode ini; aplikasi akan mengirimkannya ke Script Properties saat Anda menekan Sinkronkan.
